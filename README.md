GitHub User Explorer

A simple web application that allows users to search for GitHub profiles and explore their public information.

Features

- Search for GitHub users by username.
- Display profile picture, name, and bio.
- Show public repositories, followers, and following.
- Display the 10 most recently updated repositories.
- Loading indicator while fetching data.
- Error handling for invalid usernames and failed requests.

Technologies Used

- HTML
- CSS
- JavaScript
- GitHub REST API

What I Learned

- Fetching data from an external API.
- Using async/await and Promise.all().
- Working with JavaScript DOM manipulation.
- Handling errors with try/catch.
- Displaying dynamic data on a webpage.

How to Use

1. Clone this repository.
2. Open "index.html" in your browser.
3. Enter a GitHub username.
4. Click Search to view the user's profile.
